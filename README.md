# Personal Mini-Toolkit

## Project Purpose

This project is a menu-driven Python program containing three useful tools:

1. **Simple Calculator** – Performs addition, subtraction, multiplication, and division.
2. **To-Do List** – Allows users to add, view, and remove tasks.
3. **Number Guessing Game** – Challenges users to guess a secret number between 1 and 10.

## How to Run the Program

1. Install Python 3.
2. Open PowerShell in the project folder.
3. Run the following command:

```bash
python toolkit.py
```

4. Choose a tool from the main menu.

## Reflection

The hardest part of this project was organising the menu and keeping the indentation correct in Python. One of the challenges was making sure each tool returned to the main menu after finishing. I learned that indentation determines which block of code runs. I also learned how to use a mutable list to add, display, and remove tasks. The calculator helped me practise input, number conversion, conditions, and arithmetic operations. The number guessing game helped me understand loops and conditional statements better. If I had one more week, I would add a currency converter and improve input validation so the program can handle invalid numbers without stopping.
